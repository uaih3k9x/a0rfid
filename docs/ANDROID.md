# 安卓 RFID 助手

支持 Android 7.0 及以上、USB Host / OTG，固定横屏。配套 CH340 读写头直接使用 USB 用户态驱动。APK 位于 `android/RFID助手.apk`。

## 读取标签

1. 安装 APK，连接读写头并授予 USB 权限。
2. 放置一张标签。发现第一张后自动停止盘存，读取 EPC、TID、USER、RESERVED。
3. 读取结束后保留结果，不累计重复识别次数。点“扫描标签”可重新读取同一张或下一张。

按块读取，遇到越界或无响应会缩小块长度。每个非密码存储区最多读取 4096 字节，每区约 30 秒；触及上限、失败、取消、部分读取都会显示状态。密钥区最多读取 8 字节。自动读取使用访问密码 `00000000`。结果仅在当前会话内保留，也可复制到剪贴板。

## 快速写卡

主界面的“快速写卡”带入最近读取的内容；从列表中选择标签则带入该条记录。也可直接填写 HEX 数据。

| 区域 | 输入与操作 |
|---|---|
| TID | 从字地址 0 起，普通标签通常只读，需要支持改 TID 的卡才能更改 |
| EPC | 只填编号，自动更新目标卡 PC 的长度位，保留其他 PC 位，不写来源 CRC |
| USER | 从字地址 0 起，按填写长度操作 |
| RESERVED | 完整 8 字节，前 4 字节为 Kill 密码，后 4 字节为 Access 密码 |

勾选需要的区域，填写目标卡**当前**访问密码：

- **只检查**：回读所选范围，与输入比较，显示首个不一致的字地址、字节位置、期望值和实际值，不发送写指令。内容一致不代表区域可写。
- **写入并检查**：先读取全部勾选范围，检查可读性与范围，再按 TID → USER → EPC → RESERVED 顺序处理。非密码区内容相同则跳过写入；其余内容逐块写入、回读对比，未通过就停止后续写入。已尝试写入的区域可能部分改变，会单独标记。

RESERVED 最后写，并使用新 Access 密码回读。再次操作同一卡时，在“当前访问密码”输入新密码。某些标签会隐藏密码区内容，回读字节一致无法单独证明真实密码一致。

窗口保留输入与勾选，可换下一张卡继续。场内只放一张目标卡；多个 EPC 或响应 EPC 不一致会中止。相同 EPC 的不同实体标签无法仅靠 EPC 区分。本功能不发送 Lock/Kill 指令。

## 从剪贴板导入

读取结果 → **复制内容** → 快速写卡 → **从剪贴板导入**。

解析完整的读取结果文本，按存储区填入数据，多行按字地址拼接。EPC 仅取编号，去除 CRC、PC 及额外容量。空区域清空旧数据并取消勾选，其余区域保留勾选状态；目标卡当前访问密码不变。

部分读取数据保留来源状态提示，RESERVED 只有完整 8 字节才导入。文本截断、长度不匹配、地址不连续、重复标签或 EPC 不一致时拒绝导入，保留原输入。

## 构建与验证

构建脚本使用 macOS / Homebrew 路径，需要 JDK 17、Android SDK platform 34、build-tools 34.0.0。其他 SDK 路径可修改 `android/build.sh` 中的 `SDK`、`BT`、`JAR` 及 JDK 配置。

```sh
./android/build.sh
bash android/test.sh
adb install -r android/RFID助手.apk
```

`classes.dex` 位于 APK 根目录，minSdk 为 24、targetSdk 为 28。构建首次生成本地 `debug.keystore`，密钥不进入 Git。重新生成的签名与已发布 APK 不同，不能直接覆盖使用另一密钥签名的版本。

离线测试使用模拟标签与基于实际协议布局的合成数据，覆盖分段读取、错误响应、四区勾选组合、PC 长度、访问密码更改、回读校验、通信中断和剪贴板解析。当前共 261 项检查。

实机已在 DJI Smart Controller Enterprise（Android 7.1.2）验证安装、横屏、USB 自动读取，以及“复制内容 → 导入 → TID/EPC 只检查”。四区写卡与密码变更覆盖了离线模拟测试，尚未完成逐项实卡写入验证。
